# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-06

### Added
- Complete graph data structures with Haversine distance calculations.
- Dijkstra algorithm with node expansion tracking.
- A* algorithm with admissible Haversine heuristic.
- Held-Karp dynamic programming TSP solver for optimal multi-stop tours.
- 2-opt local search optimization for TSP tours.
- Streaming SAX-style OpenStreetMap XML parser with speed limit and road classification rules.
- Command-line interface with interactive demo mode and benchmarking.
- Comprehensive Google Test suite across all components.
- Sample OSM map data (`data/sample_map.osm`).
- GitHub Actions CI matrix across Ubuntu, Windows, and macOS.
