# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within this project, please do not open a public issue.
Instead, report it directly by emailing the maintainers or using GitHub Private Security Advisories.

Please provide:
- A clear description of the issue.
- Steps to reproduce or proof-of-concept input file.
- Potential impact and affected components.
